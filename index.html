📜 How scoring works, in every mode

Every question has a true numeric answer and an accepted range around it — usually ±10% of the true value, tighter or looser for a few tricky ones. You never see the exact range; that's on purpose.

  1. First guess: land in the accepted range and you're correct.
  2. Miss it? The second guess (the other player in Duel/Team modes, or your own retry in Solo) has to land strictly closer to the true answer than the first guess did — or, in Solo, has to land inside the accepted range itself.
  3. Ties go to whoever guessed first.

When the answer flips over, the source is shown right there — an actual citation, the way you'd cite it in your own work.

🎮 Using the buzzer

Open the buzzer page ↗ full-screen on a laptop the two players can both reach.

  • Left player presses the Left Shift key, right player presses Right Shift.
  • Whoever presses first is declared the winner on screen, with the gap in milliseconds.
  • The buzzer locks after the first press. Press Space (or click Reset) to arm it for the next question.
  • The buzzer page runs entirely on its own — it doesn't need Wi-Fi and doesn't talk to the game screen. The teacher just reads the result and enters it.

Solo mode doesn't use the buzzer — it's just you against the clock.

🎓 Setting up players

Duel and Team vs Team both let you type in names on the fly — no Admin setup required:

  • Duel: paste a list of names into "Team A" and "Team B," then call one random player from each team to face off for the whole game.
  • Team vs Team: same idea, but a fresh pair is called for every single question, so more students get a turn.
  • Both also work with a saved class roster from Admin, if you'd rather set that up once and reuse it every class.
